Conectare oficială conturi — opțional, numai citire

 
Codul pentru OAuth Google/YouTube, TikTok și Instagram este disponibil, dar dezactivat implicit. Necesită aplicații de dezvoltator, permisiuni aprobate și chei private configurate local. TikTok/Instagram necesită un callback HTTPS aprobat. Nu se solicită permisiuni de publicare.

 
Nicio conectare nu se face automat. Pentru activare configurează BERRY_ACCESS_KEY și BERRY_SOCIAL_OAUTH_ENABLED=true, apoi aprobă personal autentificarea în browser. Nu încărca niciodată secretele în GitHub sau chat.
